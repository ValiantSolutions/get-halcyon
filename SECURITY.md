## Reporting a Vulnerability

Report security vulnerabilities to **security@valiantsolutions.com**.

**Do not open public issues** for security reports (issues are disabled on
this repository in any case). Email gives us the chance to assess and fix the
problem before details become public.

Please include what you found, where (file, line, or URL), and steps to
reproduce if you have them. We will acknowledge your report and keep you
informed as we address it.

## Scope

This repository contains only the Halcyon installer script (`halcyon.sh`).
Vulnerability reports about the installer itself belong here. Reports about
the Halcyon AI Security product are also welcome at the same address —
security@valiantsolutions.com covers both.
